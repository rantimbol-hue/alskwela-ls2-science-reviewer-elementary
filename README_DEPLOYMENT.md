# ALSKwela A&E 2027 – Elementary LS2 Science

**Full installed app name:** Elementary ALS A&E Reviewer LS 2 - Science  
**Home Screen label:** Elem A&E LS2 Science

## Publish on GitHub Pages
1. Create a new public repository, e.g. `alskwela-ls2-science-reviewer-elementary`.
2. Extract the deployment ZIP. Upload `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `.nojekyll` to the repository **root** (not another folder).
3. GitHub repository → **Settings → Pages → Deploy from a branch**; select `main` and `/(root)`.
4. Copy the resulting HTTPS link and connect it in ALSKwela using Glide **Open Link**.
5. On Android, open the link directly in Chrome while online. Verify it displays **Offline files saved successfully** before adding to Home Screen.
6. Test by enabling airplane mode, reopening through Home Screen, completing a practice trial, and exporting a PDF.

## Reviewer functions
- 90 original draft questions from the uploaded Elementary LS2 Science Curriculum Guide (29 competencies).
- Fixed A, B, C sets of 30, or a balanced randomized 30-question trial.
- Every 30-question trial covers all 29 competencies, with one additional Force, Motion and Energy item.
- 9 Easy, 15 Moderate, 6 Challenging; four choices reshuffled at display time.
- English science questions; professional encouraging Taglish explanations after answer submission.
- Local storage saves trial progress; no online response collection or account.
- PDF response report generated locally; Print/Save as PDF option.

**Important:** Initial access and caching require internet. Mobile browsers can clear offline data; test on the devices actually used. This is an independent practice reviewer, not an official or psychometrically validated A&E test. Have a science teacher check the bank, then pilot it with learners.
