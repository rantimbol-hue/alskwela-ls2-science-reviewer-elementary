# 90-item option-length QA

- Average correct answer: **8.34 words**
- Average distractor: **8.08 words**
- Correct answer uniquely longest: **20 of 90**
- Largest within-item spread: **3 words**
- Every set has 8 A, 7 B, 8 C, 7 D correct answers.
- Each set contains 9 Easy, 15 Moderate, 6 Challenging.
- All 29 learning competencies are represented in every fixed set.

These checks reduce obvious answer-length clues; they do not validate item discrimination, content accuracy, or distractor plausibility. Teacher and learner pilot review is required.
